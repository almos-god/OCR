# OCR
独立开发了一款功能丰富的图形处理项目，以下是详细介绍： 功能特性 1. 截 图 功能 - 支 持 三 种 时 间 的 延 迟 ， 不 干 扰 窗 口 的 截 图 。 2 . 图 像 转 文 字 功 能 - 使 用 T e s s e r a c t O C R 文 本 识 别 软 件 包 ， 通 过 Q T 的 调 用 O C R 引 擎 来 实 现 文 本 识 别 的 功 能 。 2. 绘图功能 3. 视图功能 - 支持图像在0.1到8倍之间的缩放，使用户能够以不同的视角查看图像细节或整体效果。 - 具备图像自动位置校正功能，确保图像在不同操作下始终保持正确的显示位置，提升用户体验。  视频演示https://www.bilibili.com/video/BV1XZdKYXEuS/
